# ManyWatch

**ManyWatch** — это веб‑сервис для совместного просмотра видео и фильмов. Проект задуман как место, где можно смотреть контент как в одиночку, так и вместе с друзьями, создавая комнаты для синхронного просмотра и общения

## Идея проекта

ManyWatch помогает людям смотреть видео вместе, даже если они находятся в разных местах. Пользователь сможет запустить просмотр для себя или создать комнату, пригласить других участников и смотреть фильм, сериал, ролик или другой видеоконтент

## Основные возможности

Планируемая функциональность:

- **Одиночный просмотр** — возможность смотреть видео самостоятельно без создания комнаты
- **Совместный просмотр** — комнаты для нескольких пользователей с синхронизацией воспроизведения
- **Публичные комнаты** — открытые комнаты, к которым смогут присоединяться другие пользователи
- **Приватные комнаты** — комнаты по приглашению или ссылке для просмотра с выбранными участниками
- **Чат комнаты** — текстовое общение участников во время просмотра
- **Управление воспроизведением** — синхронизация паузы, перемотки и запуска видео между участниками комнаты
- **Поддержка видеокамер в будущем** — возможное добавление видеообщения между участниками
